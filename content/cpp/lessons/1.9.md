## Literals

A **literal** is a fixed value written directly in the source code. Unlike a variable, its value cannot change.

```cpp
5          // integer literal       (type int)
3.14       // floating-point literal (type double)
'a'        // character literal      (type char)
"hello"    // string literal
true       // boolean literal        (type bool)
```

The way a literal is written decides its type: `5` is an `int`, `5.0` is a `double`.

## Operators

An **operator** is a symbol that performs an operation. The values it works on are called **operands**. The number of operands is the operator's **arity**:

| Arity | Example | Meaning |
|---|---|---|
| Unary | `-x` | one operand (negation) |
| Binary | `a + b` | two operands |
| Ternary | `c ? a : b` | three operands (conditional) |

Each operation **produces a result**: `3 + 4` produces `7`. You have already met `=` (assignment), `<<` (insertion) and `>>` (extraction). The basic arithmetic operators are:

```cpp
5 + 2     // 7    addition
5 - 2     // 3    subtraction
5 * 2     // 10   multiplication
5 / 2     // 2    division (integers: the fraction is dropped!)
5 % 2     // 1    remainder
5.0 / 2   // 2.5  division with a double operand keeps the fraction
```

> [!warn] When both operands are integers, `/` throws away the fractional part (`7 / 2` is `3`). Use `%` to get the remainder. If either operand is a floating-point number, the result is floating-point.

## Combining operators

Operators can be chained. Multiplication and division happen before addition and subtraction, just like in math, and parentheses override the order:

```cpp
2 + 3 * 4       // 14
(2 + 3) * 4     // 20
```

## Recap

- A literal is a fixed value in the source: `5`, `3.14`, `'a'`, `"hi"`, `true`.
- An operator acts on operands; arity is unary, binary or ternary.
- Every operation produces a result.
- Integer `/` drops the fraction; `%` gives the remainder; use parentheses to control order.
