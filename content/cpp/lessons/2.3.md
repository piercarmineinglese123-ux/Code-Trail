A function that performs an action but gives no result back uses the return type **`void`**.

```cpp
void printDivider()
{
    std::cout << "----------\n";
}
```

## Calling a void function

Call it as a complete statement:

```cpp
printDivider();
```

It has no value, so it cannot be used where a value is needed:

```cpp
int x{ printDivider() };         // error: void is not a value
std::cout << printDivider();     // error
```

## Returning from a void function

A void function needs no `return`. It ends at the closing brace. You may use a bare `return;` to leave early:

```cpp
void greet(bool quiet)
{
    if (quiet)
        return;               // leave now, nothing printed
    std::cout << "Hello!\n";
}
```

You may **not** return a value from a void function: `return 5;` is an error.

> [!tip] Rule of thumb: if a function's job is to *do* something (print, update, save), make it `void`. If its job is to *compute* something the caller needs, return it.

## Recap

- `void` means "returns no value".
- Call a void function as its own statement; do not use it inside expressions.
- `return;` (no value) leaves a void function early; `return value;` is an error.
- Use `void` for actions and a value type for computations.
