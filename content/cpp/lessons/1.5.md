Input and output come from the standard library's `<iostream>` header:

```cpp
#include <iostream>
```

It gives you `std::cout` (output), `std::cin` (input) and `std::endl`. The `std::` prefix says these names live in the **standard namespace**.

## Output with `std::cout`

`std::cout` ("character output") sends text to the console. The **insertion operator** `<<` pushes the value on its right into the stream, and you can chain several in one statement:

```cpp
int x{ 5 };
std::cout << "x is " << x << '\n';    // prints: x is 5
```

Text in double quotes is a **string literal**; a single character goes in single quotes.

### New lines

Use `'\n'` to end a line. `std::endl` also ends the line, but it additionally *flushes* the output buffer, which is slower.

> [!tip] Prefer `'\n'` over `std::endl` in most code.

## Input with `std::cin`

`std::cin` reads what the user types. The **extraction operator** `>>` moves the next value from the input into a variable. Values are separated by whitespace (spaces, tabs, newlines), and extractions chain like insertions:

```cpp
int a{};
int b{};
std::cin >> a >> b;      // input "3 4"  gives  a = 3, b = 4
```

The type of the variable decides how the text is read. Reading into an `int` expects digits.

## A complete example

```cpp
#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int x{};
    std::cin >> x;
    std::cout << "Double: " << x * 2 << '\n';
    return 0;
}
```

> [!note] In this app, type the program's input into the **Input** box before pressing Run. It plays the role of the keyboard.

## Recap

- `#include <iostream>` provides `std::cout`, `std::cin` and `std::endl`.
- `std::cout << value` prints; `<<` chains.
- `std::cin >> variable` reads; `>>` chains, and whitespace separates values.
- Prefer `'\n'` to `std::endl` for new lines.
