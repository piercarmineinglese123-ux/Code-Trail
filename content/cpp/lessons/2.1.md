A **function** is a named, reusable sequence of statements. You have been writing one all along: `main`. Writing your own lets you give a name to a task and run it whenever you need it.

## Defining a function

```cpp
void printGreeting()
{
    std::cout << "Hello!\n";
}
```

- `void` says the function gives nothing back (more in lesson 2.3).
- `printGreeting` is its name.
- `()` is where parameters go (lesson 2.4); empty here.
- The body between `{ }` holds the statements to run.

## Calling a function

A **function call** runs the function. The code that makes the call is the **caller**; the function being run is the **callee**.

```cpp
#include <iostream>

void printGreeting()
{
    std::cout << "Hello!\n";
}

int main()
{
    printGreeting();   // call
    printGreeting();   // call again
    return 0;
}
```

When `printGreeting();` runs, the caller pauses, the function's statements execute, and then execution **returns** to the statement after the call. This program prints `Hello!` twice.

## Rules

- A function can call other functions, and `main` can call as many as it likes.
- Functions cannot be defined **inside** other functions. Define them side by side.
- A function must be defined (or declared) **before** it is called. Lesson 2.7 covers the declaration option.
- Do not call `main` yourself.

> [!note] Calling a function does not need `void` in front. You write only the name and parentheses: `printGreeting();`.

## Recap

- A function is a named, reusable group of statements.
- Define it with a return type, a name, `()` and a `{ }` body; call it with `name();`.
- After a call finishes, execution continues after the call in the caller.
- Functions cannot be nested, and must be known to the compiler before they are called.
