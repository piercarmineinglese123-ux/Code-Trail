**Keywords** are words C++ reserves for itself, such as `int`, `return`, `if`, `while` and `class`. There are about 90 of them, and you cannot use them as names.

An **identifier** is a name you choose for a variable, function or other entity.

## Rules for identifiers

1. Only letters (`a`-`z`, `A`-`Z`), digits and underscores. No spaces, hyphens or other symbols.
2. It cannot start with a digit.
3. It cannot be a keyword.
4. It is **case sensitive**: `score`, `Score` and `SCORE` are three different names.

| Name | Valid? | Why |
|---|---|---|
| `total_score` | yes | letters and underscore |
| `userAge` | yes | letters only |
| `2nd_place` | no | starts with a digit |
| `my-value` | no | `-` is the minus operator |
| `my value` | no | contains a space |
| `class` | no | it is a keyword |

## Naming conventions

These are not enforced by the compiler, but they make code far easier to read:

- Start variable names with a lowercase letter.
- Avoid names that start with an underscore; many of them are reserved for the implementation.
- For several words, pick `snake_case` or `camelCase` and use it consistently.
- Name a variable for what it holds. Avoid cryptic abbreviations.
- Very short names are fine for tiny scopes (like `i` in a loop), but longer scopes deserve more descriptive names.

```cpp
int n;            // unclear
int numApples;    // clear
```

## Recap

- Keywords are reserved and cannot be used as identifiers.
- Identifiers use letters, digits and underscores; they cannot start with a digit and are case sensitive.
- Start variables with a lowercase letter, avoid a leading underscore, and use one multi-word style consistently.
- Choose descriptive names.
