Before the compiler sees your code, a tool called the **preprocessor** makes a pass over each file. It does simple text processing driven by **directives**: lines that start with `#`. It does not understand C++ itself, only these directives.

The result of that pass is called a **translation unit**, and that is what the compiler actually compiles.

## `#include`

`#include` replaces the line with the full contents of another file:

```cpp
#include <iostream>    // paste the iostream header here
```

## `#define` and macros

`#define` creates a **macro**: the preprocessor replaces every occurrence of the name with the given text.

```cpp
#define GREETING "Hello"

std::cout << GREETING;   // becomes: std::cout << "Hello";
```

A macro with no replacement text just marks a name as defined:

```cpp
#define ENABLE_LOGGING
```

> [!warn] Macros ignore scope and types, and their names pollute the whole file. Avoid macros for constants and functions; later lessons show safer tools. Their main modern use is conditional compilation.

## Conditional compilation

These directives include or skip code depending on whether a name is defined:

```cpp
#ifdef ENABLE_LOGGING
std::cout << "log: starting\n";   // compiled only if ENABLE_LOGGING is defined
#endif

#ifndef ENABLE_LOGGING            // "if not defined"
// ...
#endif

#if 0
// everything here is excluded, a quick way to disable a block
#endif
```

Every `#ifdef` / `#ifndef` / `#if` must end with an `#endif`.

## Key facts

- Directives end at the end of the line and take **no semicolon**.
- A `#define` only affects the rest of the file where it appears.

## Recap

- The preprocessor runs before the compiler and handles `#` directives.
- `#include` pastes in a file; `#define` creates a macro; `#ifdef` / `#ifndef` / `#endif` compile code conditionally.
- It works on text only and knows nothing about C++ types or scope.
- Directives have no trailing semicolon.
