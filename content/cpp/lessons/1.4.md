There are two different ways to put a value into a variable, and it is important not to confuse them.

```cpp
int x;      // definition: x exists but has no value yet
x = 5;      // assignment: store 5 in x (replacing whatever was there)
```

**Assignment** changes the value of a variable that already exists. **Initialization** gives a variable its first value *at the moment it is created*.

## Four ways to initialize

```cpp
int a = 5;     // copy initialization
int b(5);      // direct initialization
int c{ 5 };    // direct list (brace) initialization
int d{};       // value initialization: d becomes 0
```

All of them start the variable off with a value. What differs is how strict they are. With braces, a **narrowing conversion**, one that could lose information, is an error:

```cpp
int e = 4.5;    // compiles, silently stores 4
int f{ 4.5 };   // error: narrowing conversion from double to int
```

The compiler catches the mistake for you instead of quietly throwing away the `.5`.

> [!tip] Best practice: initialize every variable when you define it, and prefer braces. Use empty braces `{}` when the value is going to be replaced right away, for example before you read input into the variable.

## Initialization with expressions

The starting value does not have to be a literal number. Any expression works:

```cpp
int width{ 7 };
int height{ 3 };
int area{ width * height };   // area starts as 21
```

Later, `area = 30;` would be an assignment, because `area` already exists.

## Recap

- Initialization gives a value at creation; assignment replaces the value of an existing variable.
- Forms: `int a = 5;`, `int b(5);`, `int c{ 5 };`, and `int d{};` (zero).
- Brace initialization rejects narrowing conversions such as `int f{ 4.5 };`.
- Always initialize variables, preferably with braces.
