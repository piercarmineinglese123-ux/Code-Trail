Programs are built from **statements**. A statement is a single instruction that makes the computer do something, and in C++ most statements end with a semicolon (`;`), the "full stop" of the language.

```cpp
int x;        // a declaration statement
x = 5;        // an expression statement
return 0;     // a jump statement
```

## Functions and `main`

Statements live inside **functions**. A function is a named group of statements that run one after another, from top to bottom.

Every C++ program must contain exactly one function called `main`. When the program starts, execution begins at the first statement of `main`. When `main` finishes, the program ends.

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello, world!\n";
    return 0;
}
```

Reading it line by line:

- `#include <iostream>` pulls in the standard library's input/output tools. It is a preprocessor directive, not a statement, so it has no semicolon.
- `int main()` starts the definition of `main`. The `int` says it hands back an integer.
- `{` and `}` mark the start and end of the function body.
- `std::cout << "Hello, world!\n";` prints text to the screen.
- `return 0;` gives a status code back to the operating system. `0` means "everything went fine".

> [!note] `main` is the only function that may leave out `return 0;`. If you do, the compiler adds it for you.

## Libraries

A **library** is a collection of ready-made code you can reuse. The **C++ standard library** comes with every compiler and provides input/output, strings, math and much more. You use it by writing `#include` followed by the library's name.

## Syntax and syntax errors

**Syntax** is the set of grammar rules of the language. If you break one, for example by forgetting a semicolon, the compiler stops and reports a **syntax error** with a line number.

> [!tip] Fix the first error in the list first. Later errors are often just echoes of it.

## Recap

- A statement is one instruction; most statements end with `;`.
- Statements live inside functions and run in order, top to bottom.
- Every program needs `main`; execution starts there and the program ends when it finishes.
- `#include` makes library code available.
- Breaking the grammar rules produces a syntax error.
