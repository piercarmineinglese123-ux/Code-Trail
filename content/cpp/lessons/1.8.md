**Whitespace** means spaces, tabs and newlines. C++ mostly ignores it, but not entirely. It matters in these places:

1. **Between tokens.** `return 0;` works but `return0;` is a single unknown name.
2. **Inside quoted text.** Spaces inside `"..."` are kept exactly. A string literal cannot contain a raw line break; use `\n` instead.
3. **At the end of a `//` comment.** The comment stops at the newline.

Everywhere else the compiler does not care. To the compiler these two programs are identical:

```cpp
#include <iostream>
int main(){std::cout<<"Hi\n";return 0;}
```

```cpp
#include <iostream>

int main()
{
    std::cout << "Hi\n";
    return 0;
}
```

Only one of them is pleasant to read, so formatting is about helping humans.

## Basic formatting guidelines

- Indent the body of every `{ }` by one level (a tab or four spaces).
- Put one statement on each line.
- Keep lines to about 80 characters. When a statement is too long, break it and start the continuation line with the operator:

```cpp
std::cout << "The result is "
          << result
          << '\n';
```

- Use blank lines to separate logical groups of statements.
- Choose a brace style and stay consistent. (This course puts a function's opening `{` on its own line.)
- Let a formatter such as `clang-format` do the work for you.

> [!tip] Adjacent string literals are joined by the compiler: `"Hello, " "World"` is the same as `"Hello, World"`. This lets you split long text over several lines.

## Recap

- Whitespace separates tokens, is preserved inside quotes, and a `//` comment ends at a newline.
- Otherwise the compiler ignores whitespace, so use it to make code readable.
- Indent bodies, one statement per line, keep lines short, be consistent.
