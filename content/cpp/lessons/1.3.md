Computers store data in **memory**. Picture memory as a huge row of numbered mailboxes: each one can hold data, and each has an **address** you could use to find it. In practice you rarely deal with addresses. You give things names instead.

An **object** is a region of memory that can hold a value. An object that has a name is a **variable**, and its name is called an **identifier**.

## Defining a variable

```cpp
int x;    // define a variable named x that holds an integer
```

- `int` is the **data type**. It tells the compiler how much memory to reserve and how to interpret the bits stored there (here: a whole number).
- `x` is the identifier.
- When the program runs this line, memory is set aside for `x`. Creating an object like this is called **instantiation**.

C++ is **statically typed**: a variable's type is fixed when it is defined and can never change.

## Several variables at once

Variables of the **same** type can be defined in one statement, separated by commas:

```cpp
int width, height;    // same as: int width; int height;
```

Mixing types this way is an error: `int a, double b;` does not compile. Defining one variable per line is usually easier to read and to comment.

## Define before you use

The compiler reads your code from top to bottom, so a variable must be defined before it is used:

```cpp
x = 4;     // error: x has not been defined yet
int x;
```

> [!note] Defining a variable does not give it a value. The next two lessons cover giving variables values, and what goes wrong when you forget.

## Recap

- An object is a region of memory that stores a value; a named object is a variable.
- A definition like `int x;` creates (instantiates) the variable.
- The data type decides how much memory is used and how the bits are read; it cannot change later.
- `int a, b;` defines two variables of the same type; do not mix types in one statement.
- Define a variable before you use it.
