Variables defined inside a function are **local variables**. Two ideas describe them: *scope* and *lifetime*.

## Scope: where a name can be used

A local variable's **scope** runs from the line where it is defined to the closing `}` of its block. Outside that region the name does not exist.

```cpp
int main()
{
    int x{ 1 };         // x is in scope from here...
    {
        int y{ 2 };     // y is in scope only inside these braces
    }
    // std::cout << y;  // error: y is out of scope
    return 0;
}                       // ...to here
```

Function parameters are local to their function too.

## Lifetime: when the object exists

A local variable is created when execution reaches its definition and destroyed when the block ends. After that its memory can be reused.

## Names are per function

Two functions can use the same variable name without any conflict. They are completely separate:

```cpp
int doubleIt(int n)
{
    int result{ n * 2 };
    return result;
}

int main()
{
    int result{ 10 };          // a different "result"
    int r{ doubleIt(4) };
    std::cout << result;       // prints 10, not 8
    return 0;
}
```

> [!tip] Define a variable as close as possible to where you first use it. Short scopes are easier to read and harder to misuse.

## Recap

- Local variables live inside a block; parameters are local to their function.
- Scope: from the definition to the end of the block. Lifetime: created at the definition, destroyed at the end of the block.
- Same names in different functions are independent variables.
- Keep scopes small by defining variables near their first use.
