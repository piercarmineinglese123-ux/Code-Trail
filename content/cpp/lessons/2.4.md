Functions become far more useful when the caller can give them data to work with.

## Parameters and arguments

- A **parameter** is a variable declared in the function's parentheses.
- An **argument** is the value the caller supplies for it.

```cpp
int add(int x, int y)      // x and y are parameters
{
    return x + y;
}

int main()
{
    std::cout << add(3, 4);   // 3 and 4 are arguments
    return 0;
}
```

When `add(3, 4)` runs, `x` is initialized with a **copy** of `3` and `y` with a copy of `4`. This is called **pass by value**. Changing a parameter inside the function does not change the caller's variable.

```cpp
void tryChange(int n) { n = 99; }

int a{ 5 };
tryChange(a);     // a is still 5
```

## Rules

- Parameters are separated by commas, and **each needs its own type**: `int add(int x, int y)`. Writing `int add(int x, y)` is an error.
- The caller must pass the right number of arguments, in the same order.
- Arguments can be any expression: `add(a, b * 2)`.
- Parameters work like local variables that start with the argument's value.

> [!note] If the argument type differs from the parameter type, the compiler converts it when it can (for example `int` to `double`). Narrowing conversions may lose information, so be careful.

## Recap

- A parameter is declared in the function header; an argument is the value passed at the call.
- Arguments are copied into parameters (pass by value).
- Separate parameters with commas and give each one a type.
- The number and order of arguments must match the parameters.
