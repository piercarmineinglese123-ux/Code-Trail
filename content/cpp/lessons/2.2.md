A function can send a value back to its caller. That value is the function's **return value**, and its type is the **return type** written before the name.

```cpp
int readNumber()
{
    int x{};
    std::cin >> x;
    return x;        // hand x back to the caller
}
```

## Using the returned value

A call to a value-returning function is an expression that evaluates to the returned value:

```cpp
int main()
{
    int n{ readNumber() };            // initialize n with the result
    std::cout << readNumber() * 2;    // use it inside a larger expression
    return 0;
}
```

If the caller ignores the value (`readNumber();`) the program still runs, but the value is lost.

## The `return` statement

- `return expression;` ends the function immediately and sends the value back.
- The value is converted to the declared return type.
- Any statements after a `return` in the same path never run.

> [!warn] A function with a non-`void` return type **must** return a value on every path. Reaching the closing `}` without one is undefined behavior. `main` is the one exception: it returns `0` automatically.

## One value only

A function can return **one** value. (Later lessons show how to get several results out.)

## `main`'s return value

`main` returns an `int` **status code** to the operating system. `0` means success; any other value signals a problem. You will almost always write `return 0;`.

## Recap

- The return type before the function name says what kind of value comes back.
- `return value;` ends the function and sends the value to the caller.
- A call to such a function is an expression with that value.
- Non-void functions must return a value on every path; `main` may omit it and then returns 0.
