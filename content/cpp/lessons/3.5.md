Printing values works, but scattering `std::cout` lines through your code is messy. Here are cleaner variants.

## Conditional debugging code

Wrap debug statements in conditional compilation, controlled by a single switch near the top of the file:

```cpp
#define ENABLE_DEBUG       // comment this line out to disable all debug code

#ifdef ENABLE_DEBUG
    std::cout << "DEBUG: sum = " << sum << '\n';
#endif
```

You can leave the debug code in place permanently. With the `#define` removed, the preprocessor deletes it before compiling, so it costs nothing at run time and cannot change the final program's behavior.

## Flush matters

Output can be **buffered**: held in memory and written later. If a program crashes, buffered text may never appear, and you will wrongly conclude the crash happened earlier than it did. Two ways around this:

- `std::cerr` is the standard *error* stream. It is unbuffered, so its output appears immediately. It is a good place for debug messages.
- `std::endl` flushes the buffer, which is the one time it is preferable to `'\n'`.

```cpp
std::cerr << "DEBUG: reached step 3\n";
```

## Loggers

A **logger** is a small tool or library that writes timestamped messages with levels (info, warning, error) to the console or a file. Large programs use one so that diagnostic output can be filtered, saved and turned on or off without editing code.

## Recap

- Use `#ifdef` to compile debug statements in or out from a single switch.
- Buffered output can be lost in a crash; `std::cerr` is unbuffered and ideal for debug messages.
- A logger offers organized, filterable diagnostics for bigger programs.
