An **expression** is a combination of literals, variables, operators and function calls that can be evaluated to produce a **single value**. That value is the expression's **result**.

```cpp
2            // literal: evaluates to 2
x            // variable: evaluates to the value stored in x
2 + 3        // evaluates to 5
x * 2 + 1    // evaluates to whatever x * 2 + 1 comes to
```

When the program runs, the compiler-generated code **evaluates** expressions to find their values. You can use an expression anywhere a value is expected:

```cpp
int x{ 2 };
int y{ x + 3 };          // initialized with the expression x + 3 (5)
std::cout << y * 2;      // prints the result of y * 2 (10)
```

Even assignment is an expression: `x = 5` stores 5 in `x` and evaluates to `x`.

## Expression statements

Adding a semicolon to an expression turns it into an **expression statement**, which evaluates the expression and then discards the result:

```cpp
x = 5;                  // assignment, result discarded
std::cout << x;         // output, result discarded
2 * 3;                  // legal but useless; compilers usually warn
```

## Side effects

Many expressions do more than produce a value. A **side effect** is a lasting change beyond the result: assigning to a variable (`x = 5;`), printing (`std::cout << x;`), or reading input (`std::cin >> x;`).

Expression statements exist mainly for their side effects. `2 * 3;` has none, so it does nothing useful.

## Expressions versus statements

| | Expression | Statement |
|---|---|---|
| Purpose | computes a value | performs an action |
| Example | `x + 1` | `x = x + 1;` |

> [!tip] If you can put it where a value is expected, it is an expression. A statement is a complete instruction that ends in `;`.

## Recap

- An expression combines literals, variables, operators and calls to produce one value.
- Variables evaluate to their stored value; assignment is also an expression.
- An expression statement is an expression followed by `;`; its result is discarded.
- A side effect is a change that lasts beyond the result (assigning, printing, reading).
